# Telegram Bot for Tinder

[English version](README.en.md)

Telegram-бот, який поєднує Telegram Bot API та ChatGPT для генерації Tinder-профілю, opener-повідомлень, відповідей у листуванні, рольових діалогів із селебріті та звичайних AI-відповідей. Проєкт показує, як побудувати багаторежимного чат-бота на Java з роботою зі станом діалогу, промптами й мультимедійними ресурсами.

## Мета проєкту

Цей проєкт написаний як навчальний pet-project, щоб освоїти створення Telegram-ботів на Java та інтеграцію з ChatGPT. Основна ідея полягає в тому, щоб не просто надсилати одне повідомлення у відповідь, а керувати кількома сценаріями спілкування:

- генерація опису для Tinder-профілю;
- створення першого повідомлення для знайомства;
- генерація наступного повідомлення або запрошення на побачення на основі історії листування;
- тренування діалогу з ботом у ролі відомої людини;
- окремий режим звичайних запитань до ChatGPT.

## Технології

- Java 17
- Maven
- TelegramBots `6.9.7.1`
- ChatGPT Java client `com.github.plexpt:chatgpt:4.3.0`
- OpenAI API
- Telegram Bot API
- Resource-based prompts and messages

## Що вміє бот

- показує головне меню Telegram-команд;
- генерує Tinder-профіль за відповідями користувача;
- генерує opener для першого знайомства;
- аналізує історію переписки та підказує наступне повідомлення;
- допомагає сформулювати запрошення на побачення;
- дозволяє тренувати діалог із ботом у ролі зірки;
- працює як простий ChatGPT-асистент у режимі питань і відповідей;
- надсилає текст, кнопки та зображення для різних сценаріїв.

## Структура `src`

### `src/main/java`

Основна логіка застосунку:

- `com.javarush.telegram.TinderBoltApp` - головний клас бота з усією прикладною логікою й маршрутами режимів.
- `com.javarush.telegram.MultiSessionTelegramBot` - базовий клас-обгортка над Telegram Long Polling Bot з утилітами для повідомлень, кнопок, картинок і меню.
- `com.javarush.telegram.ChatGPTService` - сервіс для роботи з ChatGPT, промптами та історією повідомлень.
- `com.javarush.telegram.DialogMode` - enum із режимами діалогу.
- `com.javarush.telegram.UserInfo` - модель даних користувача для генерації профілю або opener-повідомлення.

### `src/main/resources/messages`

Тексти інструкцій для користувача в різних режимах:

- `main.txt` - опис можливостей бота;
- `profile.txt` - вступ до генератора профілю;
- `opener.txt` - вступ до генератора opener;
- `message.txt` - пояснення режиму листування;
- `date.txt` - пояснення рольового режиму;
- `gpt.txt` - запрошення поставити питання ChatGPT.

### `src/main/resources/prompts`

Промпти для ChatGPT:

- `profile.txt` - інструкція для генерації Tinder-профілю;
- `opener.txt` - інструкція для створення першого повідомлення;
- `message_next.txt` - промпт для наступної репліки в листуванні;
- `message_date.txt` - промпт для запрошення на побачення;
- `gpt.txt` - промпт для коротких AI-відповідей;
- `date_*.txt` - сценарії рольового листування з конкретними селебріті.

### `src/main/resources/images`

Зображення, які бот відправляє для кожного сценарію, щоб зробити взаємодію більш наочною та привабливою.

## Як працює бот

1. Користувач запускає бота командою `/start`.
2. `TinderBoltApp` показує меню команд, головне зображення і текст із переліком функцій.
3. Користувач переходить у конкретний режим: `/profile`, `/opener`, `/message`, `/date` або `/gpt`.
4. Залежно від режиму бот або:
   - збирає дані поетапно через запитання;
   - пропонує inline-кнопки;
   - одразу приймає текст користувача як вхід до ChatGPT.
5. `ChatGPTService` формує запит до моделі на основі промпта та поточного повідомлення або історії.
6. Відповідь ChatGPT повертається назад у Telegram-чат.

## Режими роботи

### `/profile`

Бот по черзі запитує:

- ім'я;
- вік;
- місто;
- професію;
- хобі;
- цілі знайомства.

Після цього формує структурований текст через `UserInfo.toString()` і відправляє його в ChatGPT із промптом для генерації Tinder-профілю.

### `/opener`

Працює схоже на `/profile`, але використовує інший промпт. Мета режиму - зібрати короткий опис людини та створити для неї цікаве перше повідомлення для знайомства.

### `/message`

Бот приймає історію переписки від користувача, накопичує її в `List<String> chat` і за кнопкою:

- `message_next` генерує наступну репліку;
- `message_date` генерує запрошення на побачення.

### `/date`

Бот пропонує вибрати персонажа:

- Аріана Гранде;
- Марго Роббі;
- Зендея;
- Райан Гослінг;
- Том Харді.

Після натискання кнопки для конкретної зірки завантажується окремий системний промпт, і далі користувач може вести діалог із ChatGPT у заданій ролі.

### `/gpt`

Найпростіший режим: користувач ставить запитання, а бот відправляє його в ChatGPT з коротким системним промптом.

## Розбір класів

### `TinderBoltApp`

Призначення:
головний прикладний клас бота, де описані команди, режими та бізнес-логіка взаємодії з користувачем.

Що робить:
- успадковується від `MultiSessionTelegramBot`;
- зберігає поточний `DialogMode`;
- створює `ChatGPTService`;
- обробляє команди `/start`, `/profile`, `/opener`, `/message`, `/date`, `/gpt`;
- керує показом меню, картинок, текстів і кнопок;
- збирає дані для генерації профілю або opener;
- працює з історією листування;
- запускає Telegram-бота через `main()`.

Чому цей клас написаний:
щоб мати єдину точку координації всіх користувацьких сценаріїв і зв'язати Telegram-інтерфейс із ChatGPT-сервісом.

Що демонструє:
- роботу з Telegram updates;
- побудову state-based логіки;
- розгалуження поведінки через enum-режими;
- взаємодію з кнопками callback;
- інтеграцію зовнішнього AI-сервісу в чат-бот.

### `MultiSessionTelegramBot`

Призначення:
надати повторно використовувану базу для Telegram-бота з готовими helper-методами.

Що робить:
- наслідує `TelegramLongPollingBot`;
- приймає update і делегує його в `onUpdateEventReceived()`;
- зберігає поточний update у `ThreadLocal`;
- надає методи `getCurrentChatId()`, `getMessageText()`, `getCallbackQueryButtonKey()`;
- відправляє текст, фото, повідомлення з кнопками;
- оновлює текст уже надісланого повідомлення;
- показує або приховує меню команд;
- завантажує текстові ресурси, промпти та картинки з `resources`.

Чому цей клас написаний:
щоб не дублювати низькорівневу Telegram-логіку в прикладному класі бота.

Що демонструє:
- ООП-успадкування;
- інкапсуляцію Telegram API;
- роботу з inline buttons;
- завантаження ресурсів із classpath;
- створення reusable infrastructure layer.

### `ChatGPTService`

Призначення:
обгорнути роботу з ChatGPT у зручний сервісний клас.

Що робить:
- ініціалізує клієнт ChatGPT;
- приймає токен доступу;
- підтримує історію повідомлень у `messageHistory`;
- вміє відправити одиночний запит через `sendMessage(prompt, question)`;
- вміє задати системний контекст через `setPrompt(prompt)`;
- вміє продовжити діалог через `addMessage(question)`;
- збирає `ChatCompletion` і повертає текст відповіді моделі.

Чому цей клас написаний:
щоб відокремити AI-інтеграцію від логіки Telegram-бота.

Що демонструє:
- інтеграцію з зовнішнім API;
- збереження контексту діалогу;
- prompt engineering;
- інкапсуляцію роботи з AI-клієнтом.

### `DialogMode`

Призначення:
перелічити всі можливі режими роботи бота.

Значення:
- `MAIN`
- `PROFILE`
- `OPENER`
- `MESSAGE`
- `DATE`
- `GPT`

Що демонструє:
- використання enum для керування станом застосунку;
- більш читабельну альтернативу рядковим константам і числовим кодам.

### `UserInfo`

Призначення:
зберігати інформацію про людину, на основі якої генерується профіль або opener.

Що містить:
- ім'я;
- стать;
- вік;
- місто;
- професію;
- хобі;
- привабливість;
- дохід;
- що дратує в людях;
- цілі знайомства.

Що робить:
- накопичує дані користувача;
- перетворює заповнені поля на текст для промпта через `toString()`.

Що демонструє:
- роботу з моделлю даних;
- підготовку структурованого контексту для AI;
- базову серіалізацію об'єкта в текстовий формат.

## Як запустити

1. Встановити JDK 17.
2. Встановити Maven.
3. Створити Telegram-бота через `@BotFather`.
4. Вказати у `TinderBoltApp`:
   - `TELEGRAM_BOT_NAME`;
   - `TELEGRAM_BOT_TOKEN`;
   - `OPEN_AI_TOKEN`.
5. Зібрати проєкт:

```bash
mvn clean package
```

6. Запустити клас `TinderBoltApp`.

## Технічні примітки

- У поточній версії токени задаються прямо в коді як константи. Для production-варіанту їх краще винести в environment variables або конфігураційний файл.
- `UserInfo` містить більше полів, ніж реально збирається в поточному сценарії з 6 запитань. Це показує, що модель проєктувалася із запасом на розширення.
- У репозиторії немає окремого набору тестів, тому головний акцент тут на інтеграції, сценаріях діалогу та роботі з API.

## Висновок

Це сильний навчальний проєкт про Telegram-бота з AI-інтеграцією. Він добре демонструє навички роботи з Telegram Bot API, організацію багаторежимного діалогу, prompt-based взаємодію з ChatGPT і вміння будувати прикладний Java-проєкт навколо реального користувацького сценарію.
